# super30-python-final-loop-function-project

## Project objective

This project combines Python loops, `while` menus, functions, validation, and structured data through 12 practical programs.

## Programs completed

| Task | Program                    | Sample input/output                                      |
| ---- | -------------------------- | -------------------------------------------------------- |
| 01   | Student Result Management  | Input: `[85, 92, 78]` -> `Pass`, grade `A`               |
| 02   | Banking Application        | `2`, `100`, `1` -> balance becomes `1100`                |
| 03   | Inventory Management       | `Mouse`, `700`, `3` -> inventory value `2100`            |
| 04   | Quiz Application           | Five correct answers -> `5/5`, `100%`                    |
| 05   | Number Analysis Tool       | `[-3, 0, 4, 7, 10]` -> total `18`, average `3.6`         |
| 06   | Employee Salary Analyzer   | Salaries `50000, 70000, 70000, 60000` -> average `62500` |
| 07   | Shopping Cart              | Three books at `20` -> total `60`                        |
| 08   | Password Strength Checker  | `Python@123` -> strong                                   |
| 09   | Prime Number Analyzer      | Range `1` to `10` -> `[2, 3, 5, 7]`                      |
| 10   | Expense Tracker            | Coffee expenses `4.5` and `5` -> total `9.5`             |
| 11   | Mini Authentication System | `admin` / `python123` -> login succeeds                  |
| 12   | Python Utility Application | Calculator `8`, `+`, `2` -> `10`                         |

## How to execute

Python 3.10 or newer is recommended. There are no external dependencies.

Run any task from this folder with:

```bash
python3 task_01/main.py
python3 task_02/main.py
```

Replace `task_01` with the task you want to run. Interactive programs provide an Exit option in their menus.

The original combined notebook is available at [final_combined_python_challenges.ipynb](final_combined_python_challenges.ipynb).

## Concepts used

- `for` and `while` loops
- Functions and function docstrings
- Input validation and error handling
- Lists, dictionaries, and nested data
- Accumulators and counters
- Searching, filtering, and manual analysis
- Menu-driven applications
- Authentication state and limited attempts
- Prime-number and factorial logic

## Learning outcomes

After completing the project, I can separate calculations from user interaction, validate data before changing program state, handle empty or invalid input, reuse helper functions, and build small command-line applications with clear control flow.
