# Build and Figure Python Playlist

This repository is organized to support a beginner-to-intermediate Python learning path using an assignment and solution workflow.

## Repository structure

This week contains the complete set of Python exercises for Week 1.

- [week1](week1): parent folder for this week
- [week1/assignments](week1/assignments): starter notebooks and practice questions
- [week1/solutions](week1/solutions): completed notebooks with explanations and working code

## How to use this repository

Before starting a topic, open the matching assignment in [week1/assignments](week1/assignments) and try to solve it yourself.

If you get stuck, review the completed version in [week1/solutions](week1/solutions). Use the solution to understand the logic, then close it and attempt the task again without help.

This structure helps you:

- practice independently
- identify gaps in your understanding
- learn by doing instead of copying code
- move at your own pace through the Python playlist

## Learning flow

1. Start with the assignment.
2. Try to solve it on your own.
3. If needed, open the solution.
4. Compare your logic with the explanation.
5. Practice again without looking at the answer.

This is the core idea behind Build and Figure: build something, figure out what works, improve it, and keep learning.
